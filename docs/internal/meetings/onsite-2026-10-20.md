### Lessons Learned

| Observation | Lessons Learned |
| --- | --- |
| PR reviews didn't work out well | Provide guidance on how to conduct effective PR reviews; foster sense of ownership and intrinsic motivation to get PRs merged ASAP; keep PRs small; provide sufficient context for reviewers |
| Redundant work | Unless it is a trivial change, only work on tickets that are assigned to you |
| Lack of PR awareness | In addition to GitHub notifications, use Discord pings to ensure team members notice review requests |
| Fragmented PR discussions | Technical discussions should always take place in PR comments; if discussed verbally or in chat, post a summary on the PR |
